# Chiikawa Agent Pet v1.1.6

## Windows installer redesign

- Match the macOS DMG with a warm cream/pastel palette, a large Chiikawa companion, and Hachiware, Usagi, and Momonga artwork.
- Branded setup/uninstall icons, a multi-size executable icon, and an Installed Apps icon. Artwork is generated from the existing sprites using Windows' built-in System.Drawing.
- Concise welcome/completion instructions, optional **Launch Chiikawa Pet** on Finish, and a styled uninstall completion page. Korean Windows uses Korean installer text; other UI languages use English.
- Keep current-user installation without elevation, the running-pet guard, silent `/S` compatibility, and preference/CLI credential preservation.

Native Windows verification drives the real install/uninstall wizards and captures their rendered welcome/completion pages. It covers finish-page launch and clean exit, ordinary installed EXE click/drag/panel-close behavior, installed versions, running-pet guards, saved preferences and isolated credential sentinels, removal, and silent installation. CI uploads the rendered pages as `windows-installer-preview` for visual review. Real-account refresh and mixed-DPI behavior are not established by these account-free checks.

## Downloads

The v1.1.5 release was blocked by portable ZIP validation; its tag remains unchanged. This release fixes Windows PowerShell 5.1 portable ZIP paths so runtime licenses and other nested files use standard forward-slash entries.

Both platforms share version **1.1.6**, one tag, and one release. macOS retains the 1.1.4 DMG design without runtime changes. Quit the running pet before updating; existing preferences are preserved.

| Package | Platform |
|---|---|
| `ChiikawaPet-1.1.6-mac-arm64.dmg` | macOS 14+, Apple Silicon |
| `ChiikawaPet-1.1.6-mac-x86_64.dmg` | macOS 14+, Intel |
| `ChiikawaPet-1.1.6-win-x64-setup.exe` | Windows 10/11 x64 installer |
| `ChiikawaPet-1.1.6-win-x64.zip` | Windows 10/11 x64 portable |
| `SHA256SUMS` | Combined checksums for all four packages |

Install the Mac app into `/Applications`. Extract **all** Windows portable files together; do not move the EXE away from its DLLs. Windows packages include .NET and its license notices.

The Mac app remains ad-hoc signed, not Developer ID signed or notarized. Windows has no public code-signing certificate. This visual redesign does not remove OS security warnings. Usage endpoints are unofficial. MIT covers source code, not character artwork or provider logos; see the artwork notice. This is an unofficial fan project.

## 한국어

- **Windows 설치 화면 개선:** Mac DMG와 같은 크림색·파스텔 톤으로 맞추고 큰 치이카와와 하치와레·우사기·모몽가를 배치했습니다.
- 설치·제거 프로그램, 실행 파일과 Windows 설치된 앱 목록에 전용 아이콘을 적용했습니다. 기존 스프라이트와 Windows 기본 System.Drawing으로 이미지를 생성합니다.
- 시작·완료 안내를 다듬고 완료 화면에 **Chiikawa Pet 실행** 선택 항목을 넣었습니다. 제거 완료 화면도 같은 디자인으로 맞췄습니다. Windows 표시 언어에 따라 한국어 또는 영어로 안내합니다.
- 관리자 권한 없는 현재 사용자 설치, 실행 중 설치 방지, `/S` 무인 설치와 설정·CLI 로그인 파일 보존을 유지합니다.

Windows 검증은 실제 설치·제거 화면을 조작하고 캡처합니다. 완료 후 펫 실행·정상 종료, 설치된 EXE의 클릭·드래그·사용량 창 닫기, 버전, 실행 중 설치 방지, 설정·인증 파일 보존과 제거를 확인합니다. 실제 화면 캡처는 CI의 `windows-installer-preview` 아티팩트에서 확인할 수 있습니다. 실제 계정 조회·혼합 DPI까지 검증했다는 뜻은 아닙니다.

macOS·Windows 모두 위 표의 공통 **1.1.6** 배포본을 받으세요. Mac은 이전 DMG 디자인을 유지하며 실행 동작은 바꾸지 않았습니다. 업데이트 전에 기존 펫을 종료하고, Windows ZIP은 모든 파일을 함께 압축 해제하세요. 1.1.5는 게시하지 않았으며, 이번 버전에서 구형 PowerShell의 ZIP 경로 기록도 수정했습니다.

이번 변경에는 공인 코드 서명·공증이 포함되지 않습니다. 보안 경고는 남으며, 이미지·로고는 MIT 적용 대상이 아닙니다.

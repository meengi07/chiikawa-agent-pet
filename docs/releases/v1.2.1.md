# Chiikawa Agent Pet v1.2.1

## Claude usage with claude-swap on macOS

- Reuse cswap's schema-2 usage cache for the default Claude keychain login to reduce competing usage requests and HTTP 429 errors. Thanks to @GooTec for the investigation and proposal in #3; the hardened integration is tracked in #7.
- Verify the active token's account through Claude's OAuth profile before matching both email and organization UUID. Verification is kept only in memory for that token and repeated when the token changes. Unknown identity or duplicate matches fall back to the normal usage request/error path.
- Reuse readings under 15 minutes old without a usage-endpoint request. Only after HTTP 429 may a last-good reading up to one hour old be used. The panel keeps the original measurement time. Initial identity verification may make a profile request.
- Reject future timestamps, measurements whose quota windows have reset, unsupported schemas, and invalid cache data. A newer row for another member of the same organization cannot replace the active account's usage.
- Preserve the existing five-second keychain-reader timeout, plaintext/hex decoding, native fallback, and token validation. Custom/file-based Claude credentials and Codex behavior are unchanged. The app never writes the cswap cache or refreshes tokens.

## Usagi artwork on both platforms

- Refine all 48 shared Usagi sprite frames with thinner tapered eyebrows, highlighted eyes, a compact character-style mouth, short blush hatching, and pooled tears.
- Keep the silhouette, six moods, and blink animation on macOS and Windows.

Release creation is gated on native package and signed-update apply/restart/rollback checks for both Mac architectures and Windows installed/portable packages. App-specific update signatures are **not Apple Developer ID notarization or Windows code signing**; Gatekeeper/SmartScreen warnings can remain. Provider usage/profile endpoints are unofficial. Source code is MIT; character artwork and provider logos have separate terms. This is an unofficial fan project.

## 한국어

- **macOS Claude 사용량 개선:** 기본 키체인 로그인에서 claude-swap의 schema 2 캐시를 읽어 사용량 요청 중복과 HTTP 429를 줄입니다. #3에서 원인과 재현 방법을 알려주신 @GooTec님께 감사드립니다. 보완 작업은 #7에 정리했습니다.
- 같은 토큰의 OAuth profile로 계정을 확인한 뒤 이메일과 조직 UUID를 모두 비교합니다. 확인 결과는 토큰이 유지되는 동안 메모리에서만 재사용하며, 계정을 확인하지 못하거나 레코드가 중복되면 기존 조회·오류 경로로 돌아갑니다. 처음 계정을 확인할 때는 profile 요청이 발생할 수 있습니다.
- 측정한 지 15분 미만인 캐시는 사용량 요청 없이 재사용하고, HTTP 429일 때만 최대 1시간 전의 측정값을 사용합니다. 패널에는 원래 측정 시각을 표시합니다. 미래 시각·초기화 시각이 지난 한도·잘못된 캐시는 제외합니다.
- 기존 키체인 5초 제한·plaintext/hex 처리·native fallback·토큰 검증을 유지합니다. 커스텀 디렉터리·파일 인증과 Codex 동작은 바꾸지 않으며, 캐시 수정이나 토큰 갱신은 하지 않습니다.
- **두 OS의 우사기 디자인 개선:** 공용 스프라이트 48개에 가늘어진 눈썹, 하이라이트가 있는 눈, 작은 입, 짧은 볼 표현, 맺히는 눈물을 반영했습니다. 여섯 표정과 깜박임은 유지합니다.
- 위 표에서 macOS·Windows 공통 **1.2.1** 배포본을 받으세요. 1.2.0은 앱의 **업데이트 확인…**으로 설치할 수 있습니다. 자동 업데이트는 기존 선택을 유지하며 기본 꺼짐입니다. 1.1.6 이하에서는 한 번 직접 설치해야 합니다.

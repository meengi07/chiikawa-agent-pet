# Chiikawa Agent Pet v1.3.0

## Reliable, account-aware monitoring

- Show measurement source, age, account/plan/authentication source, refresh status and next retry separately. Persist account-bound last-good quota snapshots without credentials; restored or expired values remain clearly stale.
- Respect per-credential HTTP 429 cooldowns and `Retry-After`, including manual refresh. Do not substitute another account after an active-login failure, or keep an old account's reading after a switch.
- Parse Claude model-specific limits and Codex additional rate limits. Display provider-reported credits, spend and reset-credit counts in their own units, never as subscription quota percentages.
- Add explicit multiple Claude/Codex homes and opt-in supported saved-account discovery. Windows supports Codex Credential Manager reads and explicitly chosen Windows-accessible WSL homes. No token refresh, credential writes or automatic CLI account switching.

## Choose what the pet and menu show

- Character-picker cards always use cheerful previews. The actual pet reacts to the selected provider/account/window, with adjustable expression boundaries and a visible limiting-window explanation.
- Choose and reorder individual menu-bar/tray metrics, compact or bar rendering, reset countdowns and conservative pace estimates. Missing or stale data is not shown as a fake 0%.
- Optional quota/pace notifications establish startup/reset baselines, deduplicate crossings and rearm after recovery. Notifications, saved-account discovery and local history are off by default.
- Optional native launch-at-login and a recorded global shortcut open the panel. Registration failures are shown; existing pet, language and updater preferences are preserved. Windows uninstall removes only its own installed-copy startup entry.
- Restore Momonga's separate eyebrow strokes across all open/blinking poses without changing the other artwork.

## Local history and custom-price estimates

- Opt-in streamed Claude/Codex history, with local-calendar today/yesterday/30-day periods, replay/copy deduplication and incomplete-data warnings.
- History belongs to a CLI home, not a verified current account's bill. Quotas, credits, token history and estimated costs remain separate.
- No bundled token prices. Supply exact-model USD rates using the [documented JSON format](https://github.com/meengi07/chiikawa-agent-pet#local-history-credits-and-estimated-cost). Unknown models or special pricing tiers remain unpriced, not $0. Estimates are not subscription invoices. History and pricing files stay local.

Roadmap and acceptance: [#8](https://github.com/meengi07/chiikawa-agent-pet/issues/8). Feature comparison references [OpenUsage](https://github.com/robinebers/openusage/tree/26132ff48dd78eb2c4a9498e40424e6365f99fec); this is not a wholesale code/UI clone.

## Downloads and updates

macOS and Windows share **1.3.0**, one tag and one release.

| Package | Platform |
|---|---|
| `ChiikawaPet-1.3.0-mac-arm64.dmg` | macOS 14+, Apple Silicon |
| `ChiikawaPet-1.3.0-mac-x86_64.dmg` | macOS 14+, Intel |
| `ChiikawaPet-1.3.0-win-x64-setup.exe` | Windows 10/11 x64 installer |
| `ChiikawaPet-1.3.0-win-x64.zip` | Windows 10/11 x64 portable |
| `SHA256SUMS` | Combined checksums for all four packages |
| `updates.json`, `updates.sig` | Signed in-app update metadata |

From 1.2.0 or later, use **Check for Updates…**. Automatic updates retain your existing choice and remain off by default for new installs. Users on 1.1.6 or earlier need one manual installation. Keep the Mac app in `/Applications`; keep all Windows portable files together.

Release creation is gated on native package and signed-update apply/restart/rollback checks on both Mac architectures and Windows installed/portable packages. Real provider accounts and mixed-DPI configurations are not covered by synthetic CI. Provider endpoints are observed, unofficial contracts. App update signatures are **not Apple Developer ID notarization or Windows code signing**; Gatekeeper/SmartScreen warnings can remain. Source code is MIT; character artwork and provider logos have separate terms. This is an unofficial fan project.

## 한국어

- **계정별 사용량 신뢰도:** 출처·측정 경과 시간·계정·플랜·인증 경로·조회 상태·다음 시도를 구분합니다. 인증 정보 없이 마지막 정상값을 저장하고 재시작 시 이전 데이터로 표시합니다. 계정 변경·만료된 초기화 구간의 값을 현재 값으로 쓰지 않습니다.
- **429 대기와 모델별 한도:** 수동 새로고침도 `Retry-After`를 따릅니다. 다른 계정으로 조용히 대체하지 않으며 Claude 모델별 한도와 Codex 추가 한도를 읽습니다. 크레딧·추가 지출·리셋 크레딧은 구독 잔여%와 분리합니다.
- **표정·표시 설정:** 선택 카드는 밝은 기본 표정입니다. 실제 펫의 반응 제공자·계정·한도·경계값, 메뉴바·트레이 지표와 순서, 간략·막대 표시, 초기화 카운트다운과 조건부 사용 속도 추정을 선택합니다. 표정에 영향을 준 한도를 보여줍니다. 모몽가의 분리된 눈썹도 포함합니다.
- **선택형 OS 기능:** 잔여량·속도 알림은 첫 조회·새 초기화 구간에 기준값만 기록하고 같은 경고를 중복 발송하지 않습니다. 로그인 시 실행과 기록형 전역 패널 단축키를 제공하며 등록 실패를 알립니다. 기존 펫·언어·업데이트 설정은 유지합니다.
- **여러 로그인 경로:** CLI 홈 직접 추가와 지원하는 저장 계정 검색을 제공합니다. Windows Codex Credential Manager와 직접 지정한 WSL 접근 경로를 지원합니다. 토큰 갱신·인증 수정·자동 계정 전환은 하지 않습니다.
- **로컬 기록·비용:** 오늘·어제·최근 30일의 홈 단위 기록입니다. 계정별 청구 내역으로 귀속하지 않습니다. 내장 단가는 없고 정확한 모델별 사용자 단가가 필요합니다. 모르는 모델·특별 요금 등급은 미산정으로 남깁니다. 기록·단가 파일은 업로드하지 않습니다.
- 알림·저장 계정 검색·로컬 기록은 **기본 꺼짐**입니다. 자세한 범위와 진행 기록은 [#8](https://github.com/meengi07/chiikawa-agent-pet/issues/8), 단가 형식은 [한국어 안내](https://github.com/meengi07/chiikawa-agent-pet/blob/main/README.ko.md#로컬-기록크레딧비용-추정)를 확인하세요.

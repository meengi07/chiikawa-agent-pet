# Chiikawa Agent Pet v1.2.0

## In-app updates on macOS and Windows

- Choose **Check for Updates…** in the macOS menu-bar menu or Windows tray/pet menu. Accept the install prompt to download the latest stable version, replace the app, and restart.
- **Automatic Updates (every 6 hours)** is **off by default**. Enable it for startup/six-hour checks and automatic installation/restart. The option is saved; switching it off before installation cancels automatic application. Preview mode never checks or downloads updates.
- Preserve pet preferences and CLI sign-ins. Windows supports both per-user installation and portable x64 packages; portable updates replace only app-managed files, preserving unrelated files in the same directory.
- Verify signed release metadata with a pinned ECDSA P-256 key, then check the exact package size and SHA-256 before using it. Native helpers keep a backup until the new app acknowledges startup and restore/relaunch the previous app if startup fails.
- Gate release creation on real signed-package apply/restart, rollback, and invalid-input checks on macOS Apple Silicon/Intel and Windows installed/portable modes.

**Upgrading from 1.1.6 or earlier? Install 1.2.0 manually once.** Earlier versions do not have an updater. Later releases can be installed from the app. Keep the Mac app in `/Applications`; do not run it inside the DMG. Keep all Windows portable files together, including the updater and managed-file inventory.

## Downloads

Both platforms share version **1.2.0**, one tag, and one release. The styled Mac DMG and Windows installer remain available.

| Package | Platform |
|---|---|
| `ChiikawaPet-1.2.0-mac-arm64.dmg` | macOS 14+, Apple Silicon |
| `ChiikawaPet-1.2.0-mac-x86_64.dmg` | macOS 14+, Intel |
| `ChiikawaPet-1.2.0-win-x64-setup.exe` | Windows 10/11 x64 installer |
| `ChiikawaPet-1.2.0-win-x64.zip` | Windows 10/11 x64 portable |
| `SHA256SUMS` | Combined checksums for all four packages |
| `updates.json`, `updates.sig` | Authenticated update metadata used by both apps |

Updates download the full package, not a delta. The app-specific release signature is free cryptographic authentication, **not Apple Developer ID signing/notarization or a Windows code-signing certificate**. Gatekeeper/SmartScreen warnings can still appear. Windows ARM64 source builds do not support in-app updates.

Usage endpoints remain unofficial. MIT covers source code, not character artwork or provider logos; see the artwork notice. This is an unofficial fan project.

## 한국어

- **앱 내부 업데이트:** macOS 메뉴바 또는 Windows 트레이·펫 메뉴에서 **업데이트 확인…**을 누르세요. 설치 안내에 동의하면 최신 정식 버전을 내려받아 교체한 뒤 펫을 다시 실행합니다.
- **자동 업데이트 (6시간마다)**는 **기본 꺼짐**입니다. 켜면 시작할 때와 6시간마다 확인해 자동 설치·재실행합니다. 선택은 저장하며 설치 전에 끄면 자동 적용을 취소합니다. 미리보기에서는 업데이트를 조회하거나 내려받지 않습니다.
- 펫 설정과 CLI 로그인은 보존합니다. Windows x64 설치형·포터블을 모두 지원하며, 포터블은 앱 관리 파일만 교체해 같은 폴더의 다른 파일을 보존합니다.
- 앱에 고정한 ECDSA P-256 공개키로 릴리즈 서명을 검증하고 패키지 크기·SHA-256을 확인합니다. 네이티브 헬퍼가 새 앱의 시작 확인까지 이전 버전을 보관하며, 시작 실패 시 복원·재실행합니다.
- 두 Mac 아키텍처와 Windows 설치형·포터블의 실제 적용·재실행·복원·잘못된 입력 거부 검사를 모두 통과해야 릴리즈 초안을 만듭니다.

**1.1.6 이하 사용자는 1.2.0을 한 번 직접 설치해야 합니다.** 이전 버전에는 업데이터가 없으며 이후 릴리즈부터 앱 내부 업데이트를 사용할 수 있습니다. Mac은 `/Applications`에 설치하고, Windows 포터블은 업데이터·관리 목록을 포함한 모든 파일을 함께 유지하세요.

위 표에서 공통 **1.2.0** 배포본을 받으세요. 기존 DMG·Windows 설치 화면 디자인은 유지합니다. 전체 패키지를 교체하는 방식이며 차등 패치는 아닙니다. 자체 업데이트 서명은 Apple 공증·Windows 공인 코드 서명이 아니므로 보안 경고를 없애지는 않습니다. Windows ARM64 소스 빌드는 앱 내부 업데이트를 지원하지 않습니다. 이미지·로고는 MIT 적용 대상이 아닙니다.

# Chiikawa Agent Pet v1.1.2

## Changes

- macOS and Windows now use the same root `VERSION`, `v1.1.2` tag, and [GitHub Release](https://github.com/meengi07/chiikawa-agent-pet/releases/tag/v1.1.2). One release contains all four platform packages and one combined `SHA256SUMS`.
- Include Momonga alongside Chiikawa, Hachiware, and Usagi, with six expressions and blink animation, from the preceding platform releases.
- Include English (default) and Korean UI modes with saved language selection. Character, size, visibility, and wandering preferences persist across launches.
- Include the macOS packaged resource-loading fix: sprites and provider logos are resolved from the app's resources before the SwiftPM command-line bundle fallback.
- Include fresh macOS app-bundle assembly and clean source-launcher updates that remove obsolete files, avoiding stale resources and invalid bundle signatures while preserving preferences.
- The source launcher installs or updates `/Applications/ChiikawaPet.app` and runs that installed copy. With Hidden Bar 1.11.1 on macOS 27, copies launched from the DMG, `build/`, Downloads, or `~/Applications` can disappear even in the visible section. Use exactly `/Applications/ChiikawaPet.app`.

## Downloads

Quit the running pet before updating. macOS requires version 14 or later; Windows packages require Windows 10/11 x64.

| File | Platform | Installation |
|---|---|---|
| `ChiikawaPet-1.1.2-mac-arm64.dmg` | macOS, Apple Silicon | Open the DMG and drag the app to `/Applications`; launch the installed copy. |
| `ChiikawaPet-1.1.2-mac-x86_64.dmg` | macOS, Intel | Open the DMG and drag the app to `/Applications`; launch the installed copy. |
| `ChiikawaPet-1.1.2-win-x64-setup.exe` | Windows, x64 | Run the installer, then open Chiikawa Pet from the Start menu. |
| `ChiikawaPet-1.1.2-win-x64.zip` | Windows, x64 portable | Extract **all** files and run `ChiikawaPet.exe`. |
| `SHA256SUMS` | All four packages | Verify downloads with the single combined SHA-256 checksum file. |

Windows packages include .NET and its license notices. The installer installs for the current user without administrator privileges and provides an uninstall entry. Keep the portable EXE with its accompanying files.

The shared `release.yml` workflow requires both OS jobs to succeed before creating a draft release. Inspect the packages, checksums, and release notes before deliberately publishing it; draft creation does not publish it.

## Limitations

- The macOS app is ad-hoc signed, not Apple Developer ID signed or notarized. Windows packages have no code-signing certificate. OS security warnings may appear.
- Windows GUI and mixed-DPI behavior remain experimental and require manual Windows verification. Automated build, logic, installation, preview-startup, and uninstall checks do not establish visual correctness; this release note does not claim manual Windows GUI verification.
- Windows Credential Manager-only login storage and automatic WSL credential discovery are not supported. Usage endpoints are observed interfaces, not guaranteed stable public APIs.
- Source code is MIT licensed; character artwork and provider logos are excluded and have a separate notice in each package. This is an unofficial fan project, not affiliated with Chiikawa.

## 한국어

### 변경 사항

- macOS와 Windows가 루트 `VERSION` 하나와 `v1.1.2` 태그를 사용합니다. 하나의 [GitHub Release](https://github.com/meengi07/chiikawa-agent-pet/releases/tag/v1.1.2)에 네 배포 파일과 단일 통합 `SHA256SUMS`를 함께 제공합니다.
- 이전 OS별 릴리즈의 모몽가·여섯 가지 표정·눈 깜빡임을 포함합니다. 치이카와·하치와레·우사기도 계속 선택할 수 있습니다.
- 기본 영어 UI와 한국어 UI, 언어 선택 저장을 포함합니다. 캐릭터·크기·표시·산책 설정도 다음 실행에 유지합니다.
- macOS 배포본이 스프라이트·서비스 로고를 앱 리소스에서 먼저 찾고 SwiftPM 명령줄 번들을 대체 경로로 사용하도록 한 수정 사항을 포함합니다.
- macOS 앱 번들을 새로 구성하고 소스 런처 업데이트 시 오래된 파일을 제거합니다. 리소스와 번들 서명이 섞이는 문제를 막고 기존 설정은 유지합니다.
- 소스 런처는 `/Applications/ChiikawaPet.app`에 설치하거나 업데이트한 뒤 설치본을 실행합니다. macOS 27 + Hidden Bar 1.11.1에서는 DMG 내부·`build/`·다운로드 폴더·`~/Applications`에서 실행한 앱이 표시 영역에 있어도 숨겨질 수 있습니다. 정확히 `/Applications/ChiikawaPet.app`을 실행하세요.

### 설치와 배포

업데이트 전에 실행 중인 펫을 종료하세요. macOS 14 이상은 위 표에서 Apple Silicon 또는 Intel용 DMG를 선택해 앱을 `/Applications`로 옮긴 뒤 설치본을 실행합니다. Windows 10/11 x64는 설치 EXE를 실행하거나 포터블 ZIP의 **모든 파일을 압축 해제**한 뒤 `ChiikawaPet.exe`를 실행하세요. Windows 배포본에는 .NET이 포함되며, 설치 프로그램은 관리자 권한 없이 현재 사용자에게 설치하고 앱 제거 항목을 제공합니다. 포터블 EXE를 다른 파일과 분리하지 마세요.

네 배포 파일의 체크섬은 하나의 `SHA256SUMS`에 담습니다. 공통 `release.yml`은 두 OS 작업이 모두 성공해야 릴리즈 초안을 만듭니다. 배포 파일·체크섬·릴리즈 노트를 직접 검토한 뒤 초안 게시 여부를 결정합니다. 초안 생성은 자동 게시가 아닙니다.

### 제한 사항

- mac 앱은 ad-hoc 서명이며 Apple Developer ID 서명·공증은 없습니다. Windows 공인 코드 서명도 없어 OS 보안 경고가 나타날 수 있습니다.
- Windows 화면·혼합 DPI는 실험적 지원이며 Windows에서 직접 확인해야 합니다. 자동 빌드·로직·설치·미리보기 시작·제거 검사만으로 화면 정확성을 보장하지 않습니다. 이 노트는 Windows GUI 수동 검증을 완료했다고 주장하지 않습니다.
- Windows Credential Manager에만 저장된 로그인과 WSL 로그인 자동 검색은 지원하지 않습니다. 사용량 엔드포인트는 안정성이 보장된 공개 API가 아닙니다.
- MIT 라이선스는 소스 코드에 적용하며 캐릭터 이미지와 서비스 로고에는 적용하지 않습니다. 각 배포본의 별도 이미지 안내를 확인하세요. 치이카와와 제휴하지 않은 비공식 팬 프로젝트입니다.

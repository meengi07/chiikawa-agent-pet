# Chiikawa Agent Pet v1.1.3

## Fixes

- **Windows input crash:** closing the usage window could trigger `Deactivated` while that window was already closing, call `Close()` again, and raise `InvalidOperationException` in `Window.VerifyNotClosing`. Detach the active panel on `Closing` so deactivation cannot close it twice. The old published EXE and pre-fix source reproduced the error; fixed portable and installed EXEs pass ordinary-mode native input checks.
- Fix Windows dragging by handling mouse movement before the button consumes it. Click-versus-drag behavior and saved coordinates are retained.
- Exit Windows fully when the pet window closes, releasing the single-instance lock for relaunch. Explicit hiding still keeps the tray available.
- Keep finite Claude/Codex usage above 100% measured at **0% remaining with the crying expression**, rather than treating the provider as disconnected. Negative and nonfinite usage remains invalid.
- On macOS, read the active Claude keychain item through `/usr/bin/security` on each refresh before native fallback. Preserve custom account-directory isolation, token validation, and read-only access. Locked or untrusted items can still request authorization; stalled tool reads are stopped after five seconds.

## Verification

macOS tests and Windows logic checks pass. Windows checks now exercise real self-contained portable and installed EXEs without preview, with animation and startup refresh enabled, and fail on modal error dialogs. They cover native click, drag, usage-window close, saved positions, process exit, and mutex release. The in-process WPF regression also checks native panel close, capture loss, routed Space activation, hide/tray/show, and relaunch.

Account-free Windows checks do not establish successful real-account refresh, visual correctness, or mixed-DPI behavior on every machine. [Failing-before/passing-after evidence](https://github.com/meengi07/chiikawa-agent-pet/actions/runs/38860133645).

## Downloads

macOS and Windows share version **1.1.3**, one tag, and one release. Quit the running pet before updating. If an older Windows instance has no visible pet or tray but still runs, end `ChiikawaPet.exe` in Task Manager before installing.

Install the Mac app in `/Applications`. Extract **all** Windows portable files together; do not move the EXE away from its DLLs. Windows includes .NET and its license notices. Existing preferences are preserved.

The Mac app is ad-hoc signed, not Developer ID signed or notarized; Windows has no code-signing certificate. OS security warnings may appear. Usage endpoints are unofficial. MIT covers source code, not the character artwork or provider logos; see the artwork notice. This is an unofficial fan project.

## 한국어

- **Windows 오류 후 종료 수정:** 사용량 창이 닫히는 도중 `Deactivated`에서 다시 `Close()`를 호출해 `Window.VerifyNotClosing`의 `InvalidOperationException`이 발생했습니다. `Closing` 시점에 활성 창 참조를 먼저 해제해 중복 닫기를 막았습니다. 기존 배포 EXE와 이전 소스에서 재현했고 수정된 포터블·설치 EXE의 일반 실행 검사는 통과했습니다.
- 드래그 이벤트가 버튼에 가로막히는 문제와 펫 창을 닫아도 보이지 않는 프로세스가 남는 문제를 수정했습니다. 숨기기는 트레이를 유지하며 창 닫기는 앱을 종료합니다.
- 사용률이 100%를 넘더라도 잔여 **0%·울먹 표정**을 유지합니다. 음수·NaN·무한대는 계속 오류입니다.
- macOS Claude 키체인을 매번 시스템 `security` 도구로 먼저 읽어 계정 전환을 반영합니다. 인증 정보를 갱신하거나 키체인을 수정하지 않습니다. 잠긴 키체인이나 도구를 신뢰하지 않는 항목은 인증 창을 띄울 수 있고, 도구가 멈추면 5초 뒤 중단합니다.

검증은 미리보기에만 의존하지 않습니다. 실제 Windows 포터블·설치 EXE를 애니메이션·자동 조회가 켜진 일반 모드로 실행해 클릭·드래그·사용량 창 닫기·위치 저장·종료를 확인하며, 오류 대화상자도 실패로 처리합니다. 실제 계정 조회·외형·혼합 DPI의 수동 검증까지 완료했다는 뜻은 아닙니다.

# Chiikawa Agent Pet v1.1.4

## macOS installer redesign

- Open the DMG and follow the arrow: drag the app on the left onto the Applications shortcut on the right. Launch `/Applications/ChiikawaPet.app` after copying.
- Cream background, pink/blue installation panels, and Chiikawa, Hachiware, Usagi, and Momonga pixel art. The background includes 1× and 2× Retina representations.
- Matching transparent app and volume icon generated from the existing character sprites, with face-focused small sizes.
- English/Korean documentation and license notices are inside the signed app rather than loose installer files.
- Headless, pinned packaging tools write the Finder layout in CI. Every finished image is mounted to verify its app signature, global Applications link, background, and Finder metadata.

Local Finder verification covers the displayed layout, drag installation into `/Applications`, matching installed executable, strict ad-hoc signature validation, and successful installed-pet launch.

## Downloads

Both platforms share version **1.1.4**, one tag, and one release. Windows runtime behavior is unchanged from 1.1.3. Quit the pet before replacing or installing an update. Existing preferences are preserved.

| Package | Platform |
|---|---|
| `ChiikawaPet-1.1.4-mac-arm64.dmg` | macOS 14+, Apple Silicon |
| `ChiikawaPet-1.1.4-mac-x86_64.dmg` | macOS 14+, Intel |
| `ChiikawaPet-1.1.4-win-x64-setup.exe` | Windows 10/11 x64 installer |
| `ChiikawaPet-1.1.4-win-x64.zip` | Windows 10/11 x64 portable |
| `SHA256SUMS` | Combined checksums for all four packages |

Extract **all** Windows portable files together; do not move the EXE away from its DLLs. Windows packages include .NET and its license notices.

The Mac app remains ad-hoc signed, not Developer ID signed or notarized. Windows has no code-signing certificate. This installer redesign does not remove OS security warnings. Usage endpoints are unofficial. MIT covers source code, not character artwork or provider logos; see the artwork notice. This is an unofficial fan project.

## 한국어

- **Mac DMG 설치 화면 개선:** 왼쪽 앱을 화살표 방향으로 오른쪽 응용 프로그램 폴더에 드래그한 뒤 `/Applications/ChiikawaPet.app`을 실행하세요.
- 크림색 배경, 분홍·파랑 패널, 치이카와·하치와레·우사기·모몽가 도트 캐릭터를 배치했습니다. 배경은 일반·Retina 화면을 지원합니다.
- 기존 스프라이트로 투명 앱·볼륨 아이콘을 만들고 작은 크기에서는 얼굴이 잘 보이도록 조정했습니다.
- 영한 문서와 라이선스 안내를 앱 내부에 넣어 설치 화면에는 앱과 응용 프로그램 바로가기만 보입니다.
- Finder를 실행하지 않는 CI 패키징을 구성했습니다. 완성된 DMG의 앱 서명, 전역 응용 프로그램 연결, 배경·배치 정보를 자동 검사합니다.
- 실제 Finder 화면과 드래그 설치, 설치된 실행 파일 일치·서명 검증, 설치된 펫 실행을 확인했습니다.

macOS·Windows 모두 위 표의 공통 **1.1.4** 배포본을 사용합니다. Windows 실행 동작은 1.1.3과 같습니다. 업데이트 전에는 기존 펫을 종료하세요. 설정은 유지합니다. Windows ZIP은 모든 파일을 함께 압축 해제합니다.

이번 변경에는 공인 코드 서명·공증이 포함되지 않습니다. Mac은 ad-hoc 서명, Windows는 공인 서명 없는 상태이므로 보안 경고가 남습니다. 이미지·로고는 MIT 적용 대상이 아닙니다.

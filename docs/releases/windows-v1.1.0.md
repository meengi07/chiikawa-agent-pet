# Chiikawa Agent Pet Windows v1.1.0

## Changes

- Add Momonga alongside Chiikawa, Hachiware, and Usagi, with six expressions and blink animation.
- Add English (default) and Korean UI modes, with saved language selection.
- Preserve existing character, size, visibility, and wandering preferences across launches.

## Downloads

Requires Windows 10/11 x64. Quit the running pet before updating.

| File | Install |
|---|---|
| `ChiikawaPet-1.1.0-win-x64-setup.exe` | Run the installer, then open Chiikawa Pet from the Start menu. |
| `ChiikawaPet-1.1.0-win-x64.zip` | Extract all files and run `ChiikawaPet.exe`. |
| `SHA256SUMS` | Verify downloads with SHA-256. |

.NET and its license notices are included. The installer installs for the current user without administrator privileges and provides an uninstall entry. Do not separate the portable EXE from its accompanying files.

Windows GUI and mixed-DPI behavior remain experimental. Windows Credential Manager-only login storage and automatic WSL credential discovery are not supported. Packages have no code-signing certificate, and usage endpoints are not guaranteed stable public APIs.

Source code is MIT licensed; character artwork and provider logos are excluded and have a separate notice in each package. This is an unofficial fan project, not affiliated with Chiikawa.
